# 动效规范（对照 STM32CubeMX2 实机录屏）

> 来源：`/home/teze/视频/录屏/录屏 2026-11-15 20-33-36.mp4`（2552×1530，27.3fps，6.77s）逐帧分析。
> 目标：在"图形变形"类交互中复刻 MX2 的动效语言，不引入动画库。

## 1. 基准动效：Tilt package（封装图倾斜旋转）

| 属性 | 实测值 | 实现值 |
|---|---|---|
| 类型 | 角度补间（angular tween），整体刚体旋转 | 同 |
| 步进 | 45°（首次点击读数 **315°**，即 0→315→270→…→45→0，每次 −45°） | 45°（−45° 方向） |
| 变换对象 | 主体轮廓 + 引脚胶囊 + **胶囊内引脚名** + 外置标签**全部随转**（45° 时文字沿胶囊长轴斜排，可读） | 同（SVG `<g>` 整体 transform） |
| 文字可读性 | 旋转到倒置区间时文字绕自身中心翻转 180°，任意 45° 倍数都不倒置（225° 读数补 −180°） | 同（`.tilt-text` 自身 transform 补间） |
| 时长 | ≈180–250ms（27fps 下 2–3 帧完成） | **220ms** |
| 缓动 | ease-out，无回弹 | `cubic-bezier(0.22, 0.61, 0.36, 1)` |
| 轴心 | 画布中心 | 旋转组中心 |
| 联动 | 工具栏角度读数在动画结束更新；"Top" 复位 0° | 同 |
| 画布 | 任意角度完整可见 | 正方形视口（边长 = 对角线 + padding） |

CSS：
```css
.package-rotator {
  transform-box: view-box;
  transform-origin: center;
  transition: transform 220ms cubic-bezier(0.22, 0.61, 0.36, 1);
}
```

### 绘制约定（胶囊内/外文本，对齐 MX2 实机）

- 引脚胶囊内绘制**引脚名**（如 `PA3`/`VSS`），居中，字号按名称长度自适应（12/11/10px）；
  quad 顶/底边胶囊竖放时文字随长轴竖排（`rotate(±90°)`），倾斜后随整体刚体旋转成斜排。
- 芯片主体内部不绘制引脚名，只保留竖排芯片名、封装名与 1 号脚圆点。
- 外置标签 = `用户标签 || 功能名 || 引脚名`；电源/特殊脚无标签时显示 `名称_序号`
  （如 `VSS_7`、`GND_18`、`VDD_MCU_19`；名称已带数字尾缀如 `VSS_1`/`BOOT0` 则原样显示）。
- 引脚序号仅在悬停浮卡与 Table view 中展示，不再画入胶囊。

### 文字可读性补偿（任意 45° 倍数不倒置）

倾斜是整体刚体旋转，转到读数 **225°/135°** 等区间时文字会倒置。为此每个文字元素额外带一个
自转补偿（`PackageCanvas.vue` 的 `readableAngle` / `readabilityFlip`）：

- 文字视觉总角度 = 封装旋转 + 文字基准朝向（左/右 0°，顶/底 −90°）+ 补偿；
  补偿量只在总角度超出 `(-90°, 90°]` 时取 ±180°（或连续累加的 ±360°），因此 45° 斜排保留，
  只在倒置时刻翻转。例：读数 225°（封装旋转 135°）时左/右文字补 −180°，显示为 −45° 斜排。
- 补偿量随倾角连续累加、相邻步进差 ≤180°，CSS 过渡只会翻转 180°，不会反向绕整圈。
- 翻转与封装旋转同一节奏：`220ms cubic-bezier(0.22, 0.61, 0.36, 1)`（`.tilt-text`），
  `prefers-reduced-motion` 下时长归零。
- 基准朝向由外层 `<g transform="rotate(±90 …)">` 承担（顶/底边），文字自身只做可读性翻转，
  胶囊/标签的落位不变。

## 2. 其余变换的统一节奏

| 场景 | 时长 | 缓动 | 说明 |
|---|---|---|---|
| 按钮缩放（非滚轮） | 160ms | ease-out | 滚轮即时，避免拖影 |
| 视图切换 | 140ms | ease-out | 淡入 + 4px 上移 |
| 时钟树节点状态变化 | 200ms | linear | 描边/频率颜色过渡（error 红 / warning 橙） |
| 预设应用 | 240ms | ease-out | 目标节点一次轻微高亮脉冲（box-shadow） |
| 引脚状态变化 | 120ms | ease-out | fill/stroke 过渡 |
| 倾斜时文字可读性翻转 | 220ms | ease-out | 与封装旋转同步；仅在跨越倒置区间时翻转 180° |

## 3. 原则

1. 只用 CSS transition / Web Animations，不引入动画库。
2. 位移/旋转用 `transform`，避免触发布局；颜色过渡限定在少量节点上。
3. 所有动效尊重 `@media (prefers-reduced-motion: reduce)` → 时长归零。
4. 动画期间不改变点击语义（引脚命中区随图形一起变换）。
5. 不添加"装饰性"动画（弹跳、漂浮、循环呼吸）——MX2 的动效只服务于状态变换。
