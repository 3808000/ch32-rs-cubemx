## 1. 框图逐元素转录

图框内共 **4 个振荡源、1 个 PLL、6 个 mux（含 2 个预分频选择 mux）、11 组分频/倍频、USB 与 ADC 两条固定支路、定时器自动 ×2 逻辑**。

### 1.1 振荡源（图左列，自上而下）

| 源 | 图中文字 | 频率 | 引脚 | 去向 |
|---|---|---|---|---|
| LSI | `40kHz LSI RC` | 40 kHz | — | `IWDGCLK` → 独立看门狗；RTC 源 mux 第 1 行 |
| LSE | `32.768kHz LSE OSC` | 32.768 kHz | `OSC32_IN` / `OSC32_OUT` | RTC 源 mux 第 2 行；另经 `/128` 进 RTC 源 mux 第 3 行 |
| HSE | `3~25MHz HSE OSC` | 3–25 MHz | `OSC_IN` / `OSC_OUT` | ① PLLXTPRE 选择支路 ② SW mux HSE 行 ③ MCO ④ CSS ⑤ `/128`（RTC） |
| HSI | `8MHz HSI RC` | 8 MHz | — | ① HSI 预分频选择支路 ② SW mux HSI 行 ③ MCO |

> 图注：`本时钟树适用于 CH32F20x_D6、CH32F20x_D8、CH32V20x_D6 和 CH32V30x_D8`。
> 图注同时写：使用 USB 时 CPU 频率必须是 48/96/144MHz；使用 USB 高速功能时 USBHSPLL 时钟源只能为 HSE；从停止/待机唤醒时系统自动切换到 HSI 作主频。**注意**：图 3-3 本身没有 USBHS 框，该句是整章通用注记（USBHS 只在 d8c 图 3-2 出现，见 `v307.md`）。

### 1.2 PLL 结构

```
HSE ──┬──────────────────────> [PLLSRC mux]
      └──[PLLXTPRE ÷2]───────> [PLLSRC mux] ──> [PLLMUL ×3..16/×18] ──> PLLCLK
HSI ──┬──────────────────────> [PLLSRC mux]                         │
      └──[HSI ÷2]────────────> [PLLSRC mux]                         ├──> SW mux
                                                                     └──> USB prescaler /1,/2,/3
```

| 项 | 内容 |
|---|---|
| 预分频选择 | 图中有两级“选择 mux”：HSE 支路 `PLLXTPRE` mux（HSE 直连 / HSE÷2）；HSI 支路无名 mux（HSI 直连 / HSI÷2）。两者输出再进 `PLLSRC` 二选一 mux。 |
| PLLSRC 输入（图序上→下） | 1. HSE（经 PLLXTPRE mux） 2. HSI（经 HSI 预分频 mux） |
| 倍频 | `PLLMUL`：`*3, *4, ... *16, *18`；d8 档位 **×3…×16、×18**（无 ×2、无 ×6.5） |
| 输出 | 网络名 `PLLCLK`，图无频率读数；PLL/HCLK 上限 144MHz（DS 电气特性；图注 `HCLK 144MHz max`） |
| 寄存器旁证 | `RCC_CFGR0.PLLMUL[3:0]`（印刷 35–36 / PDF 38–39）：d6/d8 为 0000=×2 … 1111=×18（**注意寄存器含 ×2，图中 PLLMUL 框只写 ×3 起**）；`PLLXTPRE`(bit17) 0=HSE 不分频、1=HSE÷2；`PLLSRC`(bit16) 0=HSI 或 HSI÷2、1=HSE 或 HSE÷2；HSI 的 ÷2 由 `EXTEN_CTR.PLL_HSI_PRE` 控制（HAL `PllPreDiv` 仅开放 DIV1/DIV2）。 |

### 1.3 mux 及全部输入列表与顺序

| mux | 图标注 | 输入（图序：上→下） | 输出 | 控制 |
|---|---|---|---|---|
| HSE 预分频 | `PLLXTPRE` | 1. HSE 直连 2. HSE÷2 | PLLSRC 输入 1 | `RCC_CFGR0.PLLXTPRE` |
| HSI 预分频 | （无标签） | 1. HSI 直连 2. HSI÷2 | PLLSRC 输入 2 | `EXTEN_CTR.PLL_HSI_PRE`（HAL `PllPreDiv`） |
| PLL 源 | `PLLSRC` | 1. HSE 支路 2. HSI 支路 | PLLMUL | `RCC_CFGR0.PLLSRC` |
| 系统时钟 | `SW` | 1. PLLCLK 2. HSI 3. HSE | `SYSCLK` | `RCC_CFGR0.SW[1:0]`；`CSS` 从 HSE 节点汇入 |
| RTC 源 | （无标签，输出 `RTCCLK`） | 1. LSI 2. LSE 3. HSE÷128（`/128` 框） | `RTCCLK` → RTC | `RCC_BDCTLR.RTCSEL[1:0]` |
| MCO | `MCO[3:0]` | 1. HSI 2. HSE 3. PLLCLK/2 | `MCO` 引脚 | `RCC_CFGR0.MCO[3:0]`（图只画 3 行；寄存器另含 SYSCLK） |

### 1.6 频率/上限标注（图上原文）

- `40kHz`（LSI）、`32.768kHz`（LSE）、`3~25MHz`（HSE）、`8MHz`（HSI）
- `48MHz USBCLK`（USB prescaler 输出）
- `HCLK 144MHz max`
- ADC 支路无频率读数，图注/寄存器给 `ADCCLK` 上限 14MHz
- 网络名：`PLLCLK` / `SYSCLK` / `HCLK` / `PCLK1` / `PCLK2` / `ADCCLK` / `RTCCLK` / `IWDGCLK`

### 1.7 MCO 源枚举

| 层 | 枚举 |
|---|---|
| 图（上→下） | `HSI` / `HSE` / `PLLCLK/2`（图只画 3 行） |
| 寄存器 `MCO[3:0]`（印刷 35 / PDF 38，d6/d8 列） | `00xx`=无输出；`0100`=SYSCLK；`0101`=HSI；`0110`=HSE；`0111`=PLL 2 分频输出；`1000`–`1011` 为 d8c 专用（PLL2/PLL3/XT1），d8 保留 |
| 差异 | 图未画 SYSCLK 行，但寄存器 d8 支持 `0100`；建模时 MCO 源应至少含 `SYSCLK/HSI/HSE/PLL÷2` |

### 1.8 RTC / IWDG 域

- **RTC**：三源 = **LSI / LSE / HSE÷128**（图序上→下 LSI、LSE、HSE÷128），`RCC_BDCTLR.RTCSEL[1:0]`：`01`=LSE、`10`=LSI、`11`=HSE/128（d6/d8 固定 ÷128）；`RTCEN` 使能。后备域由 V_BAT 供电，LSE 可继续工作。
- **IWDG**：LSI 40kHz 直供 `IWDGCLK`，图无分频。
- **WWDG**：图中无独立节点，属 PB1 外设域。

### 2.2 关键走线

- HSE 竖干线在 nx≈0.16 从 HSE 框向下，依次分叉：PLLXTPRE 支路、SW 的 HSE 行、CSS、`/128`。
- HSI 在 nx≈0.20 分成两路：直连与 `/2`，进 HSI 预分频 mux；mux 输出向上进 PLLSRC 第 2 行。
- PLLCLK 在 nx≈0.47 向右，分叉：SW 第 1 行（上）、USB prescaler（上抽头）。
- SYSCLK 在 nx≈0.62 向右，先分三箭头给 I2S2/I2S3/TRNG（ny≈0.24–0.30），再向下进 HB prescaler。
- HCLK 是右侧长竖线（nx≈0.88），自上而下喂 Flash/HB/FCLK/÷8/PB1/PB2；PB1/PB2 分频器在竖线左侧横排，PCLK1/PCLK2 再向右出图。
- ADC prescaler 位于 PB2 行正下方（ny≈0.72），输入从 PCLK2 取，**不是 HCLK**。
- MCO 独立在左下，无水平连线进主树，宜单独分组。

## 4. 转录要素计数（供验收）

- 振荡源：4（LSI 40k / LSE 32.768k / HSE 3–25M / HSI 8M）
- PLL：1（两级预分频选择 + PLLSRC + ×3…×16/×18）
