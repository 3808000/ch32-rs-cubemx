## 1. 框图逐元素转录

图框内共 **4 个振荡源、4 个 PLL（主 PLL / PLL2 / PLL3 / USB HSPLL）、11 个 mux、16 组分频/倍频、USB FS 与 USBHS 两条 48MHz 支路、ETH/RGMII 与定时器 ×2 逻辑**。

### 1.1 振荡源（图左列，自上而下）

| 源 | 图中文字 | 频率 | 引脚 | 去向 |
|---|---|---|---|---|
| LSI | `40kHz LSI RC` | 40 kHz | — | `IWDGCLK` → 独立看门狗；RTC 源 mux 第 1 行 |
| LSE | `32.768kHz LSE OSC` | 32.768 kHz | `OSC32_IN` / `OSC32_OUT` | RTC 源 mux 第 2 行；经 `/128` 进 RTC 源 mux 第 3 行 |
| HSE | `3~25MHz HSE OSC` | 3–25 MHz | `OSC_IN` / `OSC_OUT` | ① `XTI to MCO` ② PREDIV2（PLL2/PLL3） ③ PREDIV1SRC 直连输入 ④ SW 的 HSE 行 ⑤ CSS ⑥ `/128`（RTC） |
| HSI | `8MHz HSI RC` | 8 MHz | — | ① HSI/HSI÷2 → PLLSRC ② SW 的 HSI 行 ③ HSPLLSRC（USBHS） |

> 图注：`本时钟树适用于 CH32F20x_D8C 和 CH32V30x_D8C、CH32V31x_D8C`。
> 同章文字另注：PLL2/PLL3 由 HSE 经可配置分频器 **PREDIV2** 提供时钟；USBHS 使用 HSE 时参考时钟必须与 USBHSPLL 输入时钟一致。

### 1.2 PLL 结构

#### 1.2.1 主 PLL（PLL）

```
HSE ──[PREDIV2 /1..16]──┬──> [PLL2MUL ×2.5,×4..×16,×20] ──> PLL2VCO (2×PLL2CLK)
                        └──> [PLL3MUL ×2.5,×4..×16,×20] ──> PLL3VCO (2×PLL3CLK)
HSE ───────────────────────> [PREDIV1SRC mux] ──> [PREDIV1 /1..16] ──┐
PLL2VCO ──────────────────> [PREDIV1SRC mux]                          │
                                                                       ├─> [PLLSRC mux] ─> [PLLMUL ×3..×16/×18/×6.5] ─> PLLCLK
HSI ──┬───────────────────────────────────────────────────────────────┤
      └──[HSI ÷2]─────────────────────────────────────────────────────┘
```

| 项 | 内容 |
|---|---|
| PREDIV1SRC mux 输入（图序上→下） | 1. **PLL2VCO** 2. **HSE 直连**；寄存器 `RCC_CFGR2.PREDIV1SRC`：0=HSE、1=PLL2 |
| PLLSRC mux 输入（图序上→下） | 1. **PREDIV1 输出** 2. **HSI/HSI÷2**（先经一个二选一 mux） 3. **HSE 直连**（图中长横线画到 mux 下缘）；寄存器 `RCC_CFGR0.PLLSRC`：0=HSI（或 HSI÷2），1=PREDIV1 输出（PREDIV1SRC 再选 HSE/PLL2）。图上的 HSE 直连是视觉冗余支路，寄存器路径为 `PREDIV1SRC=0 → PREDIV1 → PLLSRC=1`。 |
| 输入预分频 | PREDIV1 `/1,/2,···/15,/16`（`RCC_CFGR2.PREDIV1[3:0]`） |
| 倍频 | `PLLMUL`：`*3, *4, ... *16, *18`；d8c 实际含 **×6.5**（寄存器 1101），无 ×2；寄存器档位：0000=×18、0001=×3、0010=×4 … 1101=×6.5、1110=×15、1111=×16 |
| 输出 | `PLLCLK` → SW mux / USB prescaler；PLL 输出上限 144MHz |

#### 1.2.2 PLL2 / PLL3

| 项 | PLL2 | PLL3 |
|---|---|---|
| 输入 | HSE 经 `PREDIV2 /1,/2,···/15,/16` | 同左（同一 PREDIV2 节点） |
| 倍频 | `PLL2MUL[3:0]`：0000=×2.5、0001=×12.5、0010=×4、0011=×5、0100=×6、0101=×7、0110=×8、0111=×9、1000=×10、1001=×11、1010=×12、1011=×13、1100=×14、1101=×15、1110=×16、1111=×20 | `PLL3MUL[3:0]` 同表 |
| VCO/输出 | `PLL2VCO (2*PLL2CLK)`；PLL2CLK = PLL2VCO÷2 | `PLL3VCO (2*PLL3CLK)`；PLL3CLK = PLL3VCO÷2 |
| 去向 | ① PREDIV1SRC 的 PLL2 输入 ② ETH1GSRC 的 PLL2VCO 输入 | ① PLL3CLK（=PLL3VCO÷2，图中示例 60MHz）→ ETH-PHY ② PLL3VCO → I2S2SRC/I2S3SRC/RNGSRC ③ PLL3VCO → ETH1GSRC |

#### 1.2.3 USB HS PLL（d8c 专属）

```
HSE ──┐
      ├─> [HSPLLSRC mux] ─> [USBPREdiv /1,/2,···/7,/8] ─> [USB HSPLL] ─┬─> 480MHz → USB2.0 PHY
HSI ──┘                                                               └─> CLKFLS48MHz → [OTGFSSCR mux] → OTGFS CLK
```

| 项 | 内容 |
|---|---|
| HSPLLSRC | 图输入上→下：1. **HSI**（HSI 框向下引线） 2. **HSE**（左侧竖干线）；寄存器 `RCC_CFGR2.USBHSPLLSRC`：0=HSE、1=HSI |
| 预分频 | `USBPREdiv /1,/2,···/7,/8`（`USBHSDIV[2:0]`：000=÷1 … 111=÷8） |
| 参考频率 | 寄存器 `USBHSCLK[1:0]`：00=3MHz、01=4MHz、10=8MHz、11=5MHz（HAL `HsPllRef`） |
| 输出 | 480MHz → `USB2.0 PHY`；`CLKFLS48MHz` → `OTGFSSCR` mux |
| OTGFS 源 | `OTGFSSCR`（寄存器 `USBFSSRC`）：0=`USBCLK`（PLL 经 USB prescaler 的 48MHz）、1=`CLKFLS48MHz`（USB HSPLL 分频） |
| 限制 | 同章图注：使用 USB 高速功能时 USBHSPLL 时钟源只能为 HSE；HAL `v3.rs` 也仅允许 HSE/HSI 且要求分频后精确落在 3/4/8/5MHz |

| mux | 图标注 | 输入（图序：上→下） | 输出 | 控制 |
|---|---|---|---|---|

### 1.6 频率/上限标注（图上原文）

- `40kHz`（LSI）、`32.768kHz`（LSE）、`3~25MHz`（HSE）、`8MHz`（HSI）
- `60MHz`（PLL3CLK → ETH-PHY）
- `48MHz USBCLK`（USB prescaler 输出）
- `480MHz`（USB HSPLL → USB2.0 PHY）
- `144MHz max`（HCLK）
- `125MHz`（ETH1G_125M，来自寄存器 ETH1GSRC/图 RGMII 框）
- 网络名：`PLLCLK` / `PLL2CLK` / `PLL3CLK` / `PLL2VCO` / `PLL3VCO` / `SYSCLK` / `HCLK` / `PCLK1` / `PCLK2` / `ADCCLK` / `CLKFLS48MHz` / `OTGFS CLK`

| 层 | 枚举 |
|---|---|
| 图（上→下） | `HSE` / `HSI` / `PLLCLK/2` / `PLL2CLK` / `PLL3CLK/2` / `PLL3CLK` / `XTI` |

### 1.8 RTC / IWDG / ETH / USB 域

- **RTC**：三源 = **LSI / LSE / HSE÷128**（寄存器 `RTCSEL`：01=LSE、10=LSI、11=HSE/128，d8c 为 128 分频）；后备域 V_BAT 供电。
- **IWDG**：LSI 40kHz 直供；WWDG 属 PB1 外设域，图中无节点。
- **ETH**：PLL3CLK÷2=60MHz 供 ETH-PHY；`ETH1G_125M` 由 `ETH1GSRC` 选 PLL2VCO / PLL3VCO / 外部 PB1，经 `ETH1GEN` 门；RGMII 框内还有 `GTXC`、`RGMIION`、`GRXC`、`ETH1G_EN`、`EXT_125M` 逻辑。
- **USB FS**：PLLCLK→`USB prescaler /1,/2,/3`→48MHz USBCLK（`USBPRE`，仅 48/96/144MHz PLL 合法）。
- **USB HS**：HSE/HSI→`USBPREdiv /1..8`→USB HSPLL→480MHz PHY + CLKFLS48MHz；OTGFS 时钟由 `OTGFSSCR` 二选一。

### 2.2 关键走线

- HSE 竖干线在 nx≈0.17 向下，依次分叉：`XTI to MCO`、PREDIV2、PREDIV1SRC、PLLSRC（图中直连冗余）、SW 的 HSE 行、CSS、`/128`。
- PREDIV2 输出在 nx≈0.33 分成上下两支：上到 PLL3MUL，下到 PLL2MUL；PLL3CLK 在 nx≈0.48 再分：/2→60MHz ETH-PHY（上）、I2S2/I2S3/TRNG 三箭头（右）。
- PLL2VCO 在 nx≈0.44 向右进 PREDIV1SRC；PREDIV1→PLLSRC→PLLMUL→PLLCLK 在同一水平带（ny≈0.30）。
- PLLCLK 在 nx≈0.62 分：上到 USB prescaler（ny≈0.22）、右到 SW（ny≈0.32）。
- 蓝色 USBHS 区在右下：HSPLLSRC 输入从 HSE/HSI 竖线引下；USBPREdiv→USB HSPLL→480MHz PHY；CLKFLS48MHz 向上进 OTGFSSCR。
- HCLK 是右侧长竖线（nx≈0.90），自上而下喂 Flash/HB/FCLK/÷8/PB1/PB2；PB1/PB2/ADC 分频器在竖线左侧横排。
- MCO 独立左下，7 行输入来自 HSE/HSI/PLLCLK/PLL2CLK/PLL3CLK/XTI，布局时单独分组。
- RGMII 蓝框在左下（ny≈0.58–0.82），与主树仅通过 ETH1GSRC 的 PLL2VCO/PLL3VCO 两条竖线和 EXT_125M/PB1 外部输入相连。
