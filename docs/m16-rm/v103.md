## 1. 框图逐元素转录

图框内共 **4 个振荡源、1 个 PLL、5 个 mux、6 组分频器、3 个门控区、USB 双路输出、定时器自动 ×2 逻辑**。

### 1.1 振荡源（图左列）

| 源 | 图中文字 | 频率 | 引脚 | 备注 |
|---|---|---|---|---|
| HSI | `HSI RC` / `8MHz` | 8 MHz | — | 图左上 |
| HSE | `HSE OSC` / `4~16MHz` | 4–16 MHz | `OSC_IN` / `OSC_OUT` | 图左中；**RM 图为 4~16MHz**（数据手册另写外部时钟 8–25MHz，二者不一致，见 §3-C6） |
| LSE | `LSE OSC` / `32.768KHz` | 32.768 kHz | `OSC32_IN` / `OSC32_OUT` | 图左下 |
| LSI | `LSI RC` / `40KHz` | 40 kHz | — | 图左下最下 |

### 1.2 PLL 结构

```
HSE ──────────────┐
HSE ──[÷2]────────┤
HSI ──────────────┤ PLLSRC mux ──> [PLL] ──> PLLCLK ──> SW mux
HSI ──[÷2]────────┘                    │
                                       └──> [USB DIV /1,1.5] ──> 48MHz USBClock
```

| 项 | 内容 |
|---|---|
| 输入选择 | 4 输入 mux（**无独立标签**，即 PLLSRC），图序自上而下：① **HSI 直连** ② **HSI÷2**（`/2` 框） ③ **HSE÷2**（`/2` 框） ④ **HSE 直连** |
| 预分频 | 两个固定 `/2` 框：一个在 HSI 支路、一个在 HSE 支路（HSE 那个由 `PLLXTPRE` 控制；HSI 那个由 `EXTEN_CTR.HSIPRE` 控制） |
| 倍频 | `PLL` 框，档位由 `PLLMUL[3:0]` 选 ×2…×16（**无 ×0.5、无 ×18**） |
| 输出 | 网络名 `PLLCLK`，图无频率读数；寄存器注「PLL 输出频率不能超过 72MHz」 |
| 寄存器旁证 | 印刷 18–19 / PDF 20–21：`PLLMUL[3:0]` 0000=×2 … 1110=×16（1111 亦为 ×16 重复）；`PLLXTPRE`(bit17)：1=HSE÷2 入 PLL；`PLLSRC`(bit16)：1=HSE，0=HSI；3.3.4 文字明写 4 种来源「HSI、HSI 经 2 分频、HSE、HSE 经 2 分频」；`EXTEN_CTR.HSIPRE`(bit4)：1=HSI 直连、0=HSI÷2（印刷 281） |

### 1.3 mux 及全部输入列表与顺序

| mux | 图标注 | 输入（图序：上→下） | 输出 | 控制 |
|---|---|---|---|---|
| PLL 源 | （无标签） | 1. HSI 2. HSI÷2 3. HSE÷2 4. HSE | `PLL` | `PLLSRC` + `PLLXTPRE` + `EXTEN_CTR.HSIPRE` |
| 系统时钟 | `SW[1:0]` | 1. HSI 2. PLLCLK 3. HSE | `SYSCLK` | `SW[1:0]`；`CSS` 从 HSE 节点汇入（故障强制切 HSI） |
| SysTick | `SysTick` | 1. SYSCLK 直连 2. HCLK÷8（`/8` 框） | `SysTick` | 自动（有 SYSCLK 时用 SYSCLK，否则 HCLK/8） |
| RTC 源 | （无标签，输出 `RTC_CLK`） | 1. **HSE÷128**（`/128` 框，接 HSE 竖线） 2. LSE 直连 3. LSI | `RTC_CLK` | `RCC_BDCTLR.RTCSEL[1:0]` |
| MCO | `MCO` | 1. `SYSCLK` 2. `PLLCLK/2` 3. `HSI` 4. `HSE` | `MCO` 引脚 | `MCO[2:0]` |

> **RTC 的 ÷128 接的是 HSE，不是 LSE**：400 dpi 放大确认 `/128` 输入来自 HSE 的竖直干线（该竖线同时供 SW 的 HSE 行与 CSS），LSE 是直连进 mux 第二行。3.3.5.3 文字亦写「RTC 时钟源可由 **HSE/128**、LSE 或 LSI 提供」。M16 契约 D4 里 V103 的 RTC `inputs:[LSE,LSI]` 少了 HSE/128 这一路。

### 1.4 分频器（名称 / 档位 / 上游）

| # | 图标注 | 档位 | 上游 | 下游 |
|---|---|---|---|---|
| D1 | `/2`（HSI 支路） | ÷2 固定（`HSIPRE=0` 时生效） | HSI 8MHz | PLL 源 mux |
| D2 | `/2`（HSE 支路） | ÷2 可选（`PLLXTPRE=1`） | HSE | PLL 源 mux |
| D3 | `PLL` | ×2…×16 | PLL 源 mux | PLLCLK |
| D4 | `USB DIV` / `/1,1.5` | ÷1 或 ÷1.5（`USBPRE`） | **PLLCLK**（PLL 输出节点直接上抽头） | `48MHz USBClock` → USBD、USBFS |
| D5 | `DIV` / `/1,2,4,8,16,64,128,256,512` | 9 档 | SYSCLK | `HCLK`（标注 `HCLK`，图未写 max；寄存器/DS 上限 72/80MHz） |
| D6 | `DIV` / `/1,2,4,8,16` | 5 档 | HCLK | `PCLK1`（图框写 `PB1 Peripheral`） |

定时器自动 ×2 逻辑（图中画法，两处相同）：

```
TIM2/3/4 (Count Clk) ← [×2 框] ← 虚线框「硬件自动完成」：PB1_DIV=1 → ×2 ；PB1_DIV>1 → ×1
TIM1     (Count Clk) ← [×2 框] ← 虚线框「硬件自动完成」：PB2_DIV=1 → ×2 ；PB2_DIV>1 → ×1
```

### 1.6 频率读数标注（图上原文）

- `8MHz`（HSI）、`4~16MHz`（HSE）、`32.768KHz`（LSE）、`40KHz`（LSI）

- `ADC CLK Max=14MHz`（ADCPRE 输出）

### 1.7 MCO 源枚举

| 层 | 枚举 |
|---|---|
| 图 | `SYSCLK` / `PLLCLK/2` / `HSI` / `HSE`（上→下） |
| 寄存器 `MCO[2:0]`（印刷 18） | `0xx`=无输出；`100`=SYSCLK；`101`=HSI；`110`=HSE；`111`=PLL 时钟 2 分频输出 |
| 建议建模 | 与寄存器一致，`PLL÷2` 是硬件固定 ÷2（图仅写行名） |

### 1.8 RTC / IWDG 域

- **RTC**：mux 三源 = **HSE÷128 / LSE / LSI**，由 `RCC_BDCTLR.RTCSEL[1:0]` 选择；后备域由 V_BAT 供电。
- **IWDG**：LSI 40kHz 直供 `IWDG_CLK`（无分频框）。
- **WWDG**：图中未画（无独立节点）；WWDG 属 PB1 外设域（文字说明，非图元素）。
- 注：`RTC_CLK`/`IWDG_CLK` 在图中是**末端 readout 块**，不是可配置时钟节点。

### 2.2 上下分支位置（关键）

- HSE 竖干线在 nx≈0.21 从上（PLL mux 位）一直下到 ny≈0.42，依次分叉：PLL 源 mux（第 4 输入）、SW 的 HSE 行、CSS、`/128`。
- HSI 顶部有一条**长横线**（ny≈0.05）绕到 nx≈0.55 再下折进入 SW **最上一行**；PLLCLK 进 SW 中间行，HSE 进最下一行。这是图中最容易画错的走线：HSI→SW 不是直线，而是顶部绕行。
- USB 支路在 PLL 输出节点（nx≈0.36）**向上**抽头到 ny≈0.06，再右行。
- HPRE（`DIV /1,2,4,8,16,64,128,256,512`）在 SW 右侧偏上（nx 0.52–0.62），输出 `HCLK` 横线到 nx≈0.90 的竖总线，竖总线同时**向下**喂 B6 五排、**向上**回绕给 SysTick 的 ÷8。
- SysTick 块在 SW 下方（nx≈0.50, ny≈0.28），其 mux 两个输入：SYSCLK（上）与 HCLK÷8（下，`/8` 框在 nx≈0.63）。
- MCO 在左下角独立成簇，与主树**无水平连线**（只有 4 条源线从左/上进入），布局时宜单独成组。
- ADC 分频器（`DIV /2,4,6,8`）位于 PPRE2 行正下方，输入从 `PCLK2`（PPRE2 输出）取，不是从 HCLK。

## 4. 转录要素计数（供验收）

- 振荡源：4（HSI/HSE/LSE/LSI）
- PLL：1（4 输入 mux + 两个可选 ÷2 + ×2…×16）
- mux：5（PLL 源、SW、SysTick、RTC 源、MCO）
- 分频器：11（HSI÷2、HSE÷2、PLL、USBPRE、HPRE、PPRE1、PPRE2、ADCPRE、÷8、÷128、定时器 ×2）
- 边：45 条
- 频率读数：7（8MHz、4~16MHz、32.768KHz、40KHz、48MHz USBClock、ADC CLK Max=14MHz、HCLK 网络名）
- MCO 枚举：图 4 行 / 寄存器 5 档（含 0xx 无输出）
- RTC 域：三源（HSE÷128 / LSE / LSI）；IWDG：LSI 直供
