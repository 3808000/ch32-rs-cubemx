## 1. 框图逐元素转录

图框内共 **3 个振荡源（HSE / LSE / LSI，无 HSI）、1 个固定 ×15 PLL、3 个 mux、7 组分频、9 个外设时钟门控 + 1 个 ADC 分频支路**。

### 1.1 振荡源（图左列）

| 源 | 图中文字 | 频率 | 引脚 | 去向 |
|---|---|---|---|---|
| LSE | `外部晶振 LSE` / `X32KI` / `X32KO` | 32.768 kHz | `PA10`（X32KI）/ `PA11`（X32KO） | 32K 源 mux 第 1 行 |
| LSI | `内部时钟32K，LSI` | 32 kHz | — | 32K 源 mux 第 2 行 |
| HSE | `外部晶振 HSE` / `X32MI` / `X32MO` | 32 MHz（固定） | `X32MI` / `X32MO` | ① HSE/PLL 选择 mux ② PLL ×15 ③ `时钟分频器`（Fpll/10）输入支路（图上是 Fpll 抽头） |

> **无 HSI**：DS 与 HAL `sysctl.rs` 均无内部高速 RC；系统时钟只能来自 HSE 32MHz、PLL 480MHz 或 CK32K。

### 1.2 32K 时钟域

```
LSE 32.768kHz ──┐
                ├─> [32K mux，CLK_OSC32K_XT] ─> CK32K ─┬─> RTC
LSI 32kHz ──────┘                                      └─> SYSCLK mux（ClockSrc=Clock32K）
```

| 项 | 内容 |
|---|---|
| 32K 源 mux | 输入图序上→下：1. **LSE** 2. **LSI**；选择位 `R8_CK32K_CONFIG.RB_CLK_OSC32K_XT`（bit2）：1=外部 32K 晶振、0=内部 32K RC |
| 输出 | `CK32K` → `RTC`；同时作为 `SYSCLK mux` 的一路（`RB_CLK_SYS_MOD=11`） |
| 电源/控制 | `R8_CK32K_CONFIG`：`RB_CLK_OSC32K_FILT`（bit3，噪声过滤）、`RB_CLK_INT32K_PON`（bit1）、`RB_CLK_XT32K_PON`（bit0）；图左有 `PIN_XT32K_IE`、`CLK_XT32K_PON` 控制框 |
| 寄存器旁证 | `R8_CK32K_CONFIG`（印刷 36）：bit2 1=外部 32K、0=内部 32K；bit0/1 分别控制外部/内部 32K 振荡器电源 |

### 1.3 PLL 结构

```
HSE 32MHz ──┬─────────────────────────────> [HSE/PLL 选择 mux] ─> [RB_CLK_PLL_DIV 分频器] ─┐
            └──[PLL 倍频器 ×15=480MHz] ──> Fpll ─┘                                          ├─> [SYSCLK mux] ─> Fsys/HCLK
CK32K ────────────────────────────────────────────────────────────────────────────────────┘
Fpll ──[时钟分频器 Fpll/10=48MHz] ──> [门控 SLP_CLK_USB/2] ──> USB, USB2
```

| 项 | 内容 |
|---|---|
| PLL 输入 | **仅 HSE 32MHz**（图中 PLL 框输入只接 HSE 节点；无 HSI） |
| 倍频 | 固定 `×15 = 480MHz`（`Fpll`）；`R8_PLL_CONFIG.RB_PLL_CFG_DAT[6:0]` 复位 `1001010b` |
| PLL 输出 | `Fpll` = 480MHz；一路进 HSE/PLL 选择 mux，一路进 `时钟分频器 Fpll/10=48MHz` |
| 48MHz 支路 | `Fpll/10 = 48MHz` → USB/USB2（经 `SLP_CLK_USB/2` 门控） |
| 公式（DS 印刷 36） | `Fpll = Fck32m * 15 = 480MHz` |

### 1.4 系统时钟选择（ClockSrc 三路）

| 层 | 三路 |
|---|---|
| **RM 图/寄存器** | ① `CK32M`（HSE 32MHz）经 `RB_CLK_PLL_DIV` 分频 ② `PLL`（Fpll 480MHz）经同一分频 ③ `CK32K`（32.768kHz 或 32kHz）直接作 HCLK |
| **HAL `ClockSrc`**（`sysctl.rs`） | `Clock32K` / `HSE(u8)` / `PLL(u8)`；`HSE(div)` 与 `PLL(div)` 的 div 2..31（5 位，32 写 0） |
| 寄存器 `R16_CLK_SYS_CFG.RB_CLK_SYS_MOD[7:6]` | `00`/`10` = CK32M（默认 32MHz）进行分频；`01` = PLL（默认 480MHz）进行分频；`11` = CK32K（默认 32kHz）作为 HCLK |
| 分频 `RB_CLK_PLL_DIV[4:0]` | 最小值 2；`0` 代表最大值 32；写 `1` 将关闭 HCLK |
| 上电默认 | `Fsys = Fck32m / RB_CLK_PLL_DIV = 32MHz / 5 = 6.4MHz` |
| Fsys 范围 | 32kHz、2–10MHz、15–80MHz（DS 印刷 36） |

> 图 6-1 的画法：HSE 与 Fpll 先经一个选择 mux，再经 `分频器`，最后与 `CK32K` 一起进 `SYSCLK mux`；寄存器把这两个 mux 合并解释为 `RB_CLK_SYS_MOD` 的 4 种编码。建模时按 **ClockSrc 三路**（CK32K / HSE÷div / PLL÷div）即可，div 为同一旋钮。

### 1.5 mux 及全部输入列表与顺序

| mux | 图标注 | 输入（图序：上→下） | 输出 | 控制 |
|---|---|---|---|---|
| 32K 源 | `MUX`（上方） | 1. LSE 32.768kHz 2. LSI 32kHz | `CK32K` | `R8_CK32K_CONFIG.RB_CLK_OSC32K_XT` |
| HSE/PLL 选择 | （无标签，`分频器`前） | 1. HSE 32MHz 2. Fpll 480MHz | `分频器` | `RB_CLK_SYS_MOD`（00/10 选 HSE，01 选 PLL） |
| 系统时钟 | `MUX`（右侧） | 1. `CK32K` 2. `分频器`输出 | `HCLK` / `Fsys` | `RB_CLK_SYS_MOD`（11 选 CK32K） |

### 1.6 分频/倍频器（名称 / 档位 / 上游 → 下游）

| # | 图标注 | 档位 | 上游 | 下游 |
|---|---|---|---|---|
| D1 | `PLL 倍频器 ×15=480MHz` | 固定 ×15 | HSE 32MHz | `Fpll` |
| D2 | `分频器`（`RB_CLK_PLL_DIV`） | ÷2…÷31；`0`=÷32；写 1 关闭 HCLK | HSE/PLL 选择 mux | `SYSCLK mux` → Fsys/HCLK |
| D3 | `时钟分频器 Fpll/10=48MHz` | 固定 ÷10 | Fpll 480MHz | 48MHz → USB/USB2 门控 |
| D4 | `ADC_CLK_DIV` | 图：F（Fsys）输入；寄存器：CK32M ÷10/÷4/÷6/÷8 | 图 Fsys 轨；寄存器 CK32M 32MHz | `ADC`（寄存器值 3.2/8/5.33/4MHz） |
| D5 | `SPI_CLOCK_DIV` | 图未列档位；HAL 为线性 `fdiv=Fsys/freq` clamp 2..255 | Fsys 门控 | SPI0–1 |
| D6 | `PWM_CLOCK_DIV` | 图未列档位 | Fsys 门控 | PWMX 4–11 |
| D7 | `UARTx_DIV` | 图未列档位；HAL 为 DIV/DL 两级 | Fsys 门控 | UART0–3 |

> ADC 的图/寄存器不一致（诚实记录）：**图 6-1** 把 `ADC_CLK_DIV` 的输入画到右侧 `Fsys` 竖轨；**DS §15.2 `R8_ADC_CFG[7:6]`（印刷 89）** 明写 ADC 时钟频率选择为“基于 **CK32M** 的 10/4/6/8 分频，3.2/8/5.33/4MHz”。两者只能有一个是时钟树真相；寄存器文字是 ADC 章节的专门说明，repo `clock.json` 采信 CK32M（32MHz 固定源）与本寄存器一致。建议 diagram 按 **CK32M** 画 ADC 灰块，并在 note 记录图 6-1 的 Fsys 连线歧义。

### 1.8 频率/上限标注（图上原文 + 寄存器）

- `32MHz`（HSE，X32MI/X32MO）
- `32.768kHz`（LSE，PA10/PA11）
- `32KHz`（LSI）
- `×15=480MHz`（PLL/Fpll）
- `Fpll/10=48MHz`（USB 支路）
- `Fsys` / `HCLK` / `CK32K` 网络名
- 寄存器：Fsys 范围 32kHz、2–10MHz、15–80MHz；上电默认 6.4MHz；div 2..31（0=32）

### 1.9 RTC / 32K 域

- **RTC**：独立定时器，时基 `CK32K`；`CK32K` 由 LSE（外部 32.768kHz）或 LSI（内部 32kHz）经 32K mux 选择。RTC 与 PMU 常供电，系统复位/低功耗唤醒后时间保持。
- **BLE**：图 6-1 中 BLE 由 `Fsys` 经 `SLP_CLK_BLE` 门控；BLE 协议栈的 32K 时基仍来自 `CK32K`（M12 契约：LSE 强制用于 BLE）。
- **低功耗**：Sleep/Shutdown 下 LSE/LSI 可选保持，RTC 继续运行；`R8_HFCK_PWR_CTRL` 控制 PLL/HSE 电源与 Halt 下自动停止。

## 4. 转录要素计数（供验收）

- 振荡源：3（HSE 32M / LSE 32.768k / LSI 32k；**无 HSI**）
- PLL：1（固定 ×15=480MHz）
- mux：3（32K 源、HSE/PLL 选择、系统时钟）
- 分频/倍频：7（PLL×15、RB_CLK_PLL_DIV、Fpll/10、ADC_CLK_DIV、SPI_CLOCK_DIV、PWM_CLOCK_DIV、UARTx_DIV）
- 边：28 条（含 9 个 SLP_CLK_* 门控）
- 频率/上限读数：6（32MHz、32.768kHz、32kHz、480MHz、48MHz、Fsys 6.4MHz 默认/80MHz 上限）
