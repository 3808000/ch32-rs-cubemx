## 1. 框图逐元素转录

图框内共 **3 个振荡源、1 个 PLL、4 个 mux（PLLSRC / SW / SysTick 2 选 1 / MCO）、6 个分频器（另 1 个固定 ×2）、4 个门控与若干直出分支**。

### 1.1 振荡源（图中左列，自上而下）

| 源 | 图中文字 | 频率 | 备注 |
|---|---|---|---|
| LSI | `128kHz` / `LSI RC` | 128 kHz | 独立低速域，图中位于最上方 |
| HSE | `4~25MHz` / `HSE OSC`，左侧标注 `OSC_IN` / `OSC_OUT` 两引脚 | 4–25 MHz | 图中频段标注为 **4~25MHz** |
| HSI | `24MHz` / `HSI RC` | 24 MHz | 位于 HSE 下方偏右 |

- 图中**没有 LSE**（V003 无 32.768k 晶振域），也没有 RTC。
- 三个源都是灰色填充块（WCH 图中「灰色=内部/振荡器块」的惯例）。

### 1.2 PLL 结构

```
PLLSRC mux ──> [×2 固定] ──> PLLCLK ──> SW mux
```

| 项 | 内容 |
|---|---|
| 输入选择 | `PLLSRC` mux，**2 个输入**，图中自上而下：① HSE（来自 HSE OSC）② HSI（来自 HSI RC 24MHz） |
| 控制标注 | mux 上方标注 `RCC_CFGR0` |
| 预分频 | **无**（图中 HSE/HSI 均直连入 PLLSRC mux，没有 ÷2 框） |
| 倍频 | **固定 ×2**，图中方框 `*2`（星号形式，非 `×`） |
| 输出 | 标注 `PLLCLK`，无频率读数标注 |
| 寄存器旁证 | `RCC_CFGR0.PLLSRC`(bit16)：1=HSE 不分频送入 PLL，0=HSI 不分频送入 PLL（印刷 16）；`PLLMUL` 在 V003 无档位字段（HAL 侧亦为固定 ×2） |

### 1.3 mux 及全部输入列表与顺序

| mux | 图标注 | 输入（图序：上→下） | 输出 | 控制 |
|---|---|---|---|---|
| PLL 源选择 | `PLLSRC`（上方 `RCC_CFGR0`） | 1. HSE 　2. HSI | → `*2` → `PLLCLK` | `RCC_CFGR0.PLLSRC` |
| 系统时钟选择 | `SW` | 1. PLLCLK 　2. HSI 　3. HSE | `SYSCLK` | 图只标 `SW`；寄存器 `SW[1:0]`。另有 `CSS` 文字标在 mux 右下角的**控制输入端**（从 HSE 节点引下），**不是独立方框** |
| MCO 输出选择 | `MCO[1:0]`（图标签写 2 位） | 1. `HSI` 　2. `HSE` 　3. `PLLCLK` | `MCO` 引脚 | `MCO[1:0]`（寄存器实为 `MCO[2:0]`，见 §1.7 歧义） |

> **MCO 第一条输入的接线歧义（重要）**：该行文字写 `HSI`，但连线实际从 SYSCLK 节点（HB prescaler 输入端前的节点）引出（400 dpi 放大确认：粗 SYSCLK 竖线落到 HB prescaler 输入节点，再左折进入 MCO mux 第一行）。寄存器 `MCO[2:0]=100` 是「系统时钟 SYSCLK 输出」，`101` 才是 HSI。故图中该行是「SYSCLK 行但标成 HSI」的简写，画图时不要据此新增独立 HSI 分支。

### 1.4 分频器（名称 / 档位 / 上游）

| # | 图标注 | 档位 | 上游 | 下游 |
|---|---|---|---|---|
| D1 | `*2`（倍频器，列此备查） | ×2 固定 | PLLSRC mux | PLLCLK |
| D2 | `/3` | ÷3 固定 | **HSI RC 24MHz**（24MHz 输出线的第二个抽头，非 HSE） | `to Flash(time base)`（24/3 = 8 MHz 时基） |
| D3 | `HB prescaler` / `/1,/2.../256` | ÷1,2,…,256（图中省略号写法） | SYSCLK | `HCLK`（旁标 `48MHz max`） |
| D4 | `/8` | ÷8 固定 | HCLK | 与直连 HCLK 一起进「Core System Timer」mux |
| D5 | `ADCPRE` / `/2,/4,/6,/8,/12,/16.../64,/96,/128` | 24 档（见下） | **HCLK**（直接挂在 HCLK 竖总线上，不经 APB2） | `to ADC` |
| D6 | `/4096` | ÷4096 固定 | HCLK | 经 `peripheral clock enable` 门 → `to WWDG` |
| D7 | （无）`FCLK core free running clock` | ÷1 | HCLK | 内核自由运行时钟 |

`/3` 的上游判定依据：400 dpi 局部放大显示 ÷3 输入线来自 HSI RC 的**下方输出线**（该线继续向右进入 SW mux 的 `HSI` 行）；HSE 的竖线只上接 PLLSRC mux 与下接 SW 的 `HSE` 行，不接 ÷3。÷3 输出即 24/3=8 MHz，与「Flash time base」用途吻合。

`ADCPRE` 24 档（寄存器 `ADCPRE[4:0]`，印刷 16）：
`÷2, ÷4, ÷6, ÷8, ÷12, ÷16, ÷24, ÷32, ÷48, ÷64, ÷96, ÷128`，各档有 2 个重复编码（例如 `000xx` 与部分 `x01xx` 均给 ÷4/÷8/÷16/÷32/÷64），复位值 `00000` = **÷2**。图只画档位串，不画编码。

### 1.6 频率读数标注（图上原文）

- `128kHz`（LSI）、`24MHz`（HSI）、`4~25MHz`（HSE）
- `48MHz max`（HCLK 线旁）
- 其余节点（PLLCLK/SYSCLK/ADC）**无数字读数**，只有网络名。

### 1.7 MCO 源枚举

| 层 | 枚举 |
|---|---|
| 图 | mux 标 `MCO[1:0]`，输入行 `HSI` / `HSE` / `PLLCLK` |
| 寄存器（`RCC_CFGR0.MCO[2:0]`，印刷 15） | `0xx`=无输出；`100`=SYSCLK；`101`=HSI；`110`=HSE；`111`=PLL |
| 建议建模 | 以寄存器 4 档为准（SYSCLK/HSI/HSE/PLL）；图中无 SYSCLK 行属绘图简写 |

### 1.8 RTC / IWDG 域

- **RTC：无**（V003 无 RTC 外设，也无 LSE）。
- **IWDG**：`LSI 128kHz → IWDGCLK → IWDG`，无分频框（图中未画 ÷）。
- **WWDG**：`HCLK ÷4096` + 门控。
- **AWU**：图中未画；3.2.4 文字说明 AWU 以 LSI 为计数时基（旁证，非图元素）。

## 2. 相对排布描述（手工布局坐标参考）

图框归一化：左边界 ≈ 0.10、右边界 ≈ 0.95（页宽），上 ≈ 0.13、下 ≈ 0.93（页高）。以下 `(nx, ny)` 为图框内归一化坐标，仅供 layout 布点。

### 2.1 区带（左→右）

| 区带 | nx 范围 | 内容 |
|---|---|---|
| B0 主干线 | 0.03–0.05 | **未标注的粗竖线**，自上贯穿到下（WCH 绘图主干，无任何节点标签，勿建模为时钟节点） |
| B1 源区 | 0.05–0.28 | LSI（ny 0.06–0.13）、HSE（0.22–0.29）、HSI（0.28–0.34） |
| B2 PLL 簇 | 0.34–0.47 | PLLSRC mux（ny 0.19–0.30）、`*2`（0.42–0.46, 0.21–0.24）、`/3`（0.35–0.42, 0.30–0.34） |
| B3 系统区 | 0.58–0.70 | SW mux（0.59–0.63, 0.19–0.30）→ `SYSCLK` 竖线（nx≈0.66 下行至 0.45） |
| B4 MCO 簇 | 0.07–0.14 | MCO mux（ny 0.47–0.56，位于源区正下方、HB prescaler 左侧） |
| B5 分频/外设区 | 0.17–0.72 | 左：HB prescaler（0.17–0.31, 0.44–0.50）；中：HCLK 竖总线（nx≈0.38）；右：9 条水平分支出到 0.68–0.72 |

### 2.2 上下分支位置（关键）

- SYSCLK 从 SW mux 右侧出来 → 先向右到 nx≈0.74 → **下折**到 ny≈0.47 → 左折进 HB prescaler 右缘；下折途中在 nx≈0.30 处留下一个节点，**向左**引到 MCO mux 第一行（这就是 §1.3 的 `HSI` 行）。
- HCLK 总线是一条 nx≈0.38 的竖线，自 ny 0.47 一直画到 0.90；分出 9 条向右的水平支路，自上而下顺序固定为：
  1. `to Flash（register）`
  2. `FCLK core free running clock`
  3. `to Core System Timer`（带 `/8` + 2 选 1 mux）
  4. `to SRAM/DMA`（门）
  5. `to HB peripherals`（门）
  6. `to TIM2`（门）
  7. `to TIM1`（门）
  8. `ADCPRE → to ADC`
  9. `/4096` + 门 `→ to WWDG`
- LSI 的三条支路在 ny 0.06–0.13 之间向右扇出，顺序：GPIO → IWDG → PWR。
- HSE 一路在 ny≈0.22 右行入 PLLSRC mux，另一路沿 ny≈0.35 右行后在 nx≈0.55 处上折进 SW 最下一行（HSE 行）；HSE 节点上的圆点还向下引出一支，末端写 `CSS` 并接到 SW mux 底边的控制端（**没有 CSS 方框**，不要画成组件）。
- MCO mux 的三条输入行在 ny 0.49/0.52/0.55，均为**左→右入 mux 右缘**（与本图其它 mux 方向一致：输入在右、输出在左）。

## 3. 与 repo 现有模型（`data/devices/ch32v003f4p6/clock.json` + HAL_API_NOTES §5/§15）的差异

| # | repo 现状 | RM 图/寄存器事实 | 处理建议 |

## 4. 转录要素计数（供验收）

- 振荡源：3（LSI/HSE/HSI）
- PLL：1（2 输入 mux + 固定 ×2，无 prediv）
- mux：4（PLLSRC / SW / SysTick 2 选 1 / MCO）
- 分频器：6（`/3`、HB prescaler、`/8`、ADCPRE、`/4096`、`/1` FCLK）＋1 倍频器
- 边：31 条（含 CSS 两条、MCO 三条、HCLK 九条扇出）
- 频率读数：4（128kHz / 24MHz / 4~25MHz / 48MHz max）
- MCO 枚举：图 3 行 / 寄存器 4 档
- RTC 域：无；IWDG：LSI 直供；WWDG：HCLK÷4096
