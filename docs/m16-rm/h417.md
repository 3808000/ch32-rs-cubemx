## 1. 框图逐元素转录

图框内共 **4 个振荡源、5 个 PLL（SYS + USBHS + USBSS + ETH + SERDES）、15 个 mux、17 组分频/倍频、双核 HPRE/FPRE 分叉、11 个 CFGR2 KernelMux**。

### 1.1 振荡源（图左列，自上而下）

| 源 | 图中文字 | 频率 | 引脚 | 去向 |
|---|---|---|---|---|
| LSI | `40kHz LSI RC` | 40 kHz | — | `IWDGCLK` → `to IWDG/LPTIM1/LPTIM2`；RTC 源 mux 第 1 行 |
| LSE | `32.768kHz LSE OSC` | 32.768 kHz | `OSC32_IN` / `OSC32_OUT` | RTC 源 mux 第 2 行；`to LPTIM1/LPTIM2`；经 `/512` 进 RTC 源 mux 第 3 行 |
| HSE | `25MHz HSE OSC` | 25 MHz（图固定值；DS 为 5–32MHz、典型 25MHz） | `X1` / `X0` | ① PLLSRC ② ETH PLL ③ USBHSPLLSRC ④ USBSS PLL ⑤ SERDES PLL ⑥ SW 的 HSE 行 ⑦ CSS ⑧ `/512`（RTC） |
| HSI | `25MHz HSI RC` | 25 MHz | — | ① PLLSRC ② USBHSPLLSRC ③ SW 的 HSI 行 ④ `to IWDG/LPTIM1/LPTIM2` |

> HSE 在图中标 `25MHz HSE OSC`（X1/X0），是 RM 的典型配置；数据手册给出外部 HSE 5–32MHz（repo `hxtal` 5–32、default 25 与 DS 一致）。HSE 旁路模式最高 25MHz（§3.3.2）。

### 1.2 PLL 结构

#### 1.2.1 主 SYS PLL

```
USBSS_PLL_CLK ──────┐
USBHS_PLL_CLK ──────┤
SERDES_PLL_CLK/2 ───┤
HSE ────────────────┤ PLLSRC mux ─> [PLL_SRC_DIV /1..64] ─> [SYS PLL] ─> [PLLMUL ×4,×6..×59] ─> PLLCLK
ETH_PLL_CLK ────────┤
HSI ────────────────┘
```

| 项 | 内容 |
|---|---|
| PLLSRC 图序（上→下） | 1. `USBSS_PLL_CLK` 2. `USBHS_PLL_CLK` 3. `SERDES_PLL_CLK/2` 4. `HSE` 5. `ETH_PLL_CLK` 6. `HSI` |
| PLLSRC 寄存器 `RCC_PLLCFGR.PLLSRC[2:0]` | `000`=HSI、`001`=HSE、`100`=USBHS_PLL(480MHz)、`101`=ETH_PLL(500MHz)、`110`=USBSS_PLL(125MHz)、`111`=SERDES_PLL/2 |
| 输入分频 | `PLL_SRC_DIV[5:0]`：000000=÷1、000001=÷2 … 111111=÷64 |
| 倍频 | `PLLMUL[4:0]`：×4、×6、×7、×8、×8.5、×9、×9.5、×10、×10.5、×11、×11.5、×12、×12.5、×13、×14、×15、×16、×17、×18、×19、×20、×22、×24、×26、×28、×30、×32、×34、×36、×38、×40、×59（无 ×5、×21、×23 等洞） |
| 输出 | `PLLCLK` → `SYSPLL_SEL` mux；主 PLL 上限按 DS/配方（400MHz V5F、160MHz V3F/HCLK） |
| 使能/锁定 | `RCC_CTLR.PLLON` / `PLLRDY`；`SYSPLL_GATE` 切换至 PLL 前置位 |

#### 1.2.2 辅助 PLL

| PLL | 结构 | 输出/去向 |
|---|---|---|
| **ETH PLL** | 固定 500MHz；图 `500M` → `20M`（÷25）与 `ETHCLK_100M`（÷5） | `ETH_PLL_CLK`（主 PLL 输入 5）、`ETHCLK_100M`、`ETHCLK_20M`（USBHS PLL 输入 3、ETH1GSRC/ADCSRC/UHSIFSRC/HSADCSRC/LTDCSRC 的 ETH 支路） |
| **USBHS PLL** | 输入 mux `USBHSPLLSRC`：00=HSE、01=HSI、10=ETHCLK_20M、11=分频后的 SYS_PLL_CLK（`USBHSPLL_IN_DIV[4:0]` ÷1…÷32）；参考频率 `USBHSPLL_REFESEL[1:0]`：00=25MHz、01=20MHz、10=24MHz、11=32MHz；输出 480MHz，经 `/8`→`UTMI_CLK` | `USBHS_PLL_CLK`（主 PLL 输入 2、USBSFSSRC、UHSIFSRC、HSADCSRC、LTDCSRC、MCO 的 UTMI_CLK） |
| **USBSS PLL** | 固定 125MHz；参考 `USBSSPLL_REFESEL[1:0]`：000=20、001=24、010=25、011=30、100=32、101=40、110=60、111=80MHz；`PIPEON` 与 125M 相与后供 USBSS | `USBSS_PLL_CLK`（主 PLL 输入 1、ETH1GSRC、MCO 的 USBSS_PLL_CLK/2） |
| **SERDES PLL** | 倍频 `SERDESPLL_MUL[3:0]`：0000=×25、0001=×28、0010=×30、0011=×32、0100=×35、0101=×38、0110=×40、0111=×45、1000=×50、1001=×56、1010=×60、1011=×64、1100=×70、1101=×76、1110=×80、1111=×90；输出 `SERDES_PLL_CLK` 与 `/2` | `SERDES_PLL_CLK/2`（主 PLL 输入 3、ETH1GSRC、LTDCSRC、MCO 的 /16 支路） |

> 使能位（`RCC_CTLR`）：`PLLON`、`USBHS_PLLON`、`USBSS_PLLON`、`ETH_PLLON`、`SERDES_PLLON`，对应 `PLLRDY/USBHS_PLLRDY/USBSS_PLLRDY/ETH_PLLRDY/SERDES_PLLRDY`。

#### 1.2.3 系统 PLL 选择与 SW

`SYSPLL_SEL` mux（`RCC_PLLCFGR.SYSPLL_SEL[2:0]`，仅 `SYSPLL_GATE=0` 可写）：

| 值 | 源 |
|---|---|
| `0xx` | `PLL_CLK`（主 SYS PLL） |
| `100` | `USBHS_PLL`（480MHz） |
| `101` | `ETH_PLL`（500MHz） |
| `110` | `SERDES_PLL/2` |
| `111` | `USBSS_PLL`（125MHz） |

`SYSPLL_SEL` 输出再与 HSI、HSE 一起进 `SW` mux（`RCC_CFGR0.SW[1:0]`：00=HSI、01=HSE、10=PLL 输出、11 不可用）→ `SYSCLK`；`CSS` 从 HSE 汇入。

### 1.8 双核 HPRE / FPRE 分叉（关键）

```
SYSCLK ─> [HB prescaler /1,/2,···/512] ─> [HPRE mux] ─> to CORE1 (RISC-V5F)
                                                │
                                                └─> [FPRE /2,/4] ─> HCLK ─┬─> to CORE0 (RISC-V3F)
                                                                           ├─> HB Bus/memory/DMA
                                                                           ├─> /8 → Core System timer
                                                                           └─> PPRE2/外设
```

- **HPRE**（`RCC_CFGR0.HPRE[3:0]`）：0xxx=÷1、1000=÷2、1001=÷4、1010=÷8、1011=÷16、1100=÷64、1101=÷128、1110=÷256、1111=÷512。V5F 核时钟 = SYSCLK/HPRE。
- **FPRE**（`RCC_CFGR0.FPRE[1:0]`）：00=÷1、01=÷2、1x=÷4。HCLK/V3F = V5F 时钟/FPRE。
- **400MHz 配方**（`with_sysclk_400m_v5f_400m_v3f_100m_*`）：主 PLL 25MHz×16=400MHz；HPRE=÷1 → V5F 400MHz；FPRE=÷4 → V3F/HCLK 100MHz；PCLK1=PCLK2=100MHz。
- **repo 合成语义**：`clock.json.ahb` 不是单一 HPRE，而是 **HPRE×FPRE 合成**（`[1,4]`），用于让 `HCLK` 复现 100MHz；V5F 不在 `ClockFrequencies` 中建模。M16 aux 用 `V5F`/`V3F` readout 表达两核，不改 ahb 合成语义。
